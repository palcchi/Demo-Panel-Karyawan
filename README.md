# Attendly - Demo Website Karyawan

Demo statis sistem karyawan untuk presentasi/pengajuan. Dibuat dengan HTML, CSS, dan JavaScript murni tanpa backend atau database.

## Fitur
- Dashboard karyawan
- Absensi masuk dan pulang
- Jadwal mingguan
- Pengajuan cuti, libur, sakit, dan izin
- Riwayat pengajuan
- Ringkasan gaji dan slip
- Profil karyawan
- Responsive untuk desktop, tablet, dan mobile
- Data dummy langsung terisi

## Menjalankan
Buka `index.html` langsung di browser atau deploy sebagai static site.

## GitHub Pages
1. Buka Settings > Pages.
2. Pilih `Deploy from a branch`.
3. Pilih branch `main` dan folder `/root`.
4. Simpan.

Tidak ada data asli dan tidak ada koneksi database. Semua hanya untuk demonstrasi UI dan alur sistem.
